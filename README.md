# Анализ телефонных переговоров менеджеров

## Документационная основа — v0.5

Статус: сбор и согласование требований. Реализация не начата.

На этом этапе не создаются workflow n8n, SQL, окончательная структура Supabase и программный код.

## Цель

Создать универсальный шаблон продукта анализа телефонных переговоров менеджеров, который легко адаптируется под разные компании через настройки и адаптеры, без переписывания общего ядра.

## Принцип документации

Каждое существенное правило должно иметь один основной документ. README служит навигацией и не дублирует подробные спецификации.

Этот репозиторий является источником истины по новому продукту. Документация будет дополняться и уточняться по мере согласования требований и последующего проектирования.

Репозиторий `Shablon_bot_pervichnogo_obrascheniya` используется только как образец организации документации, ролей, планов, передачи между сессиями и проверки перед выпуском. Изменять его запрещено.
