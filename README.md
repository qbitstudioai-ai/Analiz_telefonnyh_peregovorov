# Анализ телефонных переговоров менеджеров

Универсальный шаблон продукта анализа телефонных переговоров менеджеров. Конкретные компании подключаются через настройки и адаптеры; общая логика продукта не должна переписываться при обычном внедрении.

## Статус и границы

Документационная основа и логическое техническое проектирование DOC-01—DOC-19 завершены и прошли итоговый аудит 25 сентября 2026 года. Павел разрешил реализацию в **рабочем Supabase в строго ограниченном контуре schema `shablon`**. Это разрешение не распространяется на существующие посторонние схемы/данные, destructive actions или переключение реального трафика без отдельного решения.

Разрешено по одной задаче создавать SQL, JSON workflow и программный код по [плану реализации](docs/WORKPLAN_IMPLEMENTATION.md), а также применять согласованные изменения к schema `shablon` в рабочем Supabase. Фактическое применение и проверки фиксируются отдельно; чужие схемы, рабочие данные и destructive действия не входят в это разрешение.

Рабочий репозиторий является источником истины:
https://github.com/qbitstudioai-ai/Analiz_telefonnyh_peregovorov

Репозиторий `Shablon_bot_pervichnogo_obrascheniya` используется как образец организации документации, ролей, планов, передачи между сессиями, проверок и безопасного выпуска. Его бизнес-логика не переносится. Общие архитектурные решения фиксируются в каждом продукте отдельно и адаптируются к его данным.

## Состояние подготовки

Требования продукта, общая архитектура, российское размещение, жизненный цикл, взаимодействие инструментов, дашборд руководителя, надёжность обработки, блок аудио/транскрипции/ролей/приватности DOC-06—DOC-09, изоляция компаний DOC-10, контракты DOC-11, словарь данных DOC-12, версионирование DOC-13, доказательная модель DOC-14, административные границы DOC-16, lifecycle общей базы знаний DOC-17 и эксплуатационный release checklist DOC-18 зафиксированы. [Итоговый аудит DOC-19](docs/DOCUMENTATION_AUDIT.md) завершён. GATE-01 пройден. Дополнительно зафиксирован GATE-02: разрешена реализация в рабочем Supabase только внутри schema `shablon`; существующие сторонние схемы/данные и destructive production actions не разрешены автоматически.

Реальные записи разговоров, транскрипции, документы клиентов, токены, пароли, дампы БД и другие частные сведения в публичный репозиторий не загружаются.
