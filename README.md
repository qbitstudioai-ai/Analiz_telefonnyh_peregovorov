# Анализ телефонных переговоров менеджеров

Универсальный шаблон продукта анализа телефонных переговоров менеджеров. Конкретные компании подключаются через настройки и адаптеры; общая логика продукта не должна переписываться при обычном внедрении.

## Статус и границы

Подготовлена документационная основа v0.7. Текущий режим — **только документация**.

SQL, JSON workflow, программный код, настройки n8n/Supabase, сервер и production в текущем режиме не изменяются. Наличие будущей задачи в плане не означает разрешение на реализацию.

Рабочий репозиторий является источником истины:
https://github.com/qbitstudioai-ai/Analiz_telefonnyh_peregovorov

Репозиторий `Shablon_bot_pervichnogo_obrascheniya` используется только как образец организации документации, ролей, планов, передачи между сессиями, проверок и безопасного выпуска. Его бизнес-логика не переносится и сам репозиторий не изменяется.

## С чего начинает новая сессия

1. [Инструкция ChatGPT](docs/CHATGPT_INSTRUCTIONS.md).
2. [Текущее состояние](docs/PROJECT_STATE.md).
3. [План создания шаблона](docs/WORKPLAN_TEMPLATE.md) либо, после готовности шаблона, [план внедрения компании](docs/WORKPLAN_CLIENT_DEPLOYMENT.md).
4. [Правила передачи между сессиями](docs/SESSION_HANDOFF.md).
5. Только профильные документы одной выбранной задачи по карте ниже.

**Одна небольшая задача — одна сессия — один проверяемый результат — одна передача.**

## Будущие документы

Надёжность и защита от дублей, хранение аудио, интеграционные контракты, изоляция компаний, словарь данных, версионирование, доказательства, точные метрики, админ-панель и проверка выпуска будут заполняться отдельными задачами с постоянными ID из плана.

Реальные записи разговоров, транскрипции, документы клиентов, токены, пароли, дампы БД и другие частные сведения в публичный репозиторий не загружаются.
