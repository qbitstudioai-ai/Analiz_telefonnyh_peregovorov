# Анализ телефонных переговоров менеджеров

Универсальный шаблон продукта анализа телефонных переговоров менеджеров. Конкретные компании подключаются через настройки и адаптеры; общая логика продукта не должна переписываться при обычном внедрении.

## Статус и границы

Документационная основа v1.0 подготовлена. 25 сентября 2026 года по команде Павла начат следующий этап — техническое проектирование требований в документации. Реализация ещё не начиналась.

SQL, JSON workflow, программный код, настройки n8n/Supabase, сервер и production в текущем режиме не изменяются. Наличие будущей задачи в плане не означает разрешение на реализацию.

Рабочий репозиторий является источником истины:
https://github.com/qbitstudioai-ai/Analiz_telefonnyh_peregovorov

Репозиторий `Shablon_bot_pervichnogo_obrascheniya` используется как образец организации документации, ролей, планов, передачи между сессиями, проверок и безопасного выпуска. Его бизнес-логика не переносится. Общие архитектурные решения фиксируются в каждом продукте отдельно и адаптируются к его данным.

## Состояние подготовки

Требования продукта, общая архитектура, российское размещение, жизненный цикл, взаимодействие инструментов, дашборд руководителя, надёжность обработки, временное аудио и протокол проверки транскрибации/диаризации зафиксированы. Остальные технические требования по назначению ролей, приватности, правам, контрактам, версиям, мониторингу и выпуску закрываются отдельными задачами до соответствующей реализации/production.

Реальные записи разговоров, транскрипции, документы клиентов, токены, пароли, дампы БД и другие частные сведения в публичный репозиторий не загружаются.
