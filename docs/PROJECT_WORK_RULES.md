# Правила ведения проекта — навигация

Этот файл сохранён для совместимости с начальной документацией. Он не является вторым источником нормативных правил.

Основные документы:

- роли, разрешения и порядок работы ChatGPT — [CHATGPT_INSTRUCTIONS](CHATGPT_INSTRUCTIONS.md);
- правила изменения документации — [DOCUMENTATION_RULES](DOCUMENTATION_RULES.md);
- постоянные ID и последовательность задач — [WORKPLAN_TEMPLATE](WORKPLAN_TEMPLATE.md);
- текущий режим и одна следующая задача — [PROJECT_STATE](PROJECT_STATE.md);
- передача между сессиями — [SESSION_HANDOFF](SESSION_HANDOFF.md).

Базовый принцип проекта: **одна небольшая задача — одна сессия — один проверяемый результат**.

Павел принимает бизнес-решения и выполняет понятные ручные действия. ChatGPT руководит проектом и проверяет результат. Помощник в VSCode выполняет порученные задачи разработки, тестов и Git.

В текущем режиме разрешена только документация. Реализация начинается только после явного изменения режима в PROJECT_STATE и команды Павла.
