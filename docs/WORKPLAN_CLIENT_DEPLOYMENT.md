# План внедрения готового шаблона в компанию

Этот документ описывает будущую последовательность внедрения **после** готовности и выпуска шаблона. Сейчас он не разрешает реализацию и не утверждает, что технические решения уже выбраны.

Реальные записи, транскрипции, документы компании, секреты и частные параметры хранятся вне публичного репозитория.

## Принцип

Обычное внедрение должно менять настройки и адаптеры компании, а не CORE.

У компании может быть свой источник звонков, фильтрация, CRM, канал обратной связи, промт и критерии оценки. Общий актуальный источник знаний компании может использоваться несколькими независимыми продуктами через отдельные ограниченные права.

## Будущая последовательность

Каждая строка — отдельная небольшая задача/сессия. Точные технические действия появятся только после готовности документации и шаблона.

## Выпуск и откат

Подготовка production не равна включению production. Переключение выполняется только после явного разрешения Павла.

До рабочего включения должны быть известны критерии остановки, резервная копия, предыдущая совместимая версия и способ отката. Восстановление одной компании не должно затирать новые данные других компаний.

Файл в GitHub, импорт workflow, подключение Credentials, активация и проверка реального звонка — разные факты и фиксируются отдельно.
