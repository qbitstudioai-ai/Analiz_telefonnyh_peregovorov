## Принятые требования верхнего уровня

- настройки конкретной компании не живут внутри CORE;
- источники и выходные каналы подключаются через адаптеры;
- фильтрация централизована и может отличаться по компаниям;
- локальный Whisper — кандидат для испытаний, а не утверждённое окончательное решение;
- для анализа обязательно различать МЕНЕДЖЕР/КЛИЕНТ;
- персональные данные скрываются до аналитической LLM по будущим точным правилам;
- Supabase не хранит аудио постоянно;
- анализ настраивается промтом и опирается на разрешённые знания компании;
- менеджер получает обучающую обратную связь;
- руководитель получает отдельный дашборд с историей и доказательной базой.
