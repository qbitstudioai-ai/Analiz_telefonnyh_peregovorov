# Текущее состояние проекта

Статус: сбор требований. Реализация не начата.

## Уже согласовано

- Создаётся универсальный шаблон анализа телефонных переговоров.
- Настройки конкретной компании не живут внутри CORE.
- Источники и выходные системы подключаются через адаптеры.
- Входные разговоры фильтруются до CORE.
- Фильтр должен быть простым и централизованным.
- Разные компании могут анализировать все разговоры или только выбранные типы.
- Предварительный первый вариант транскрибации — локальный Whisper.
- Для анализа обязательно различать менеджера и клиента.
- Диаризация тестируется отдельно; предварительно рассматриваются pyannote.audio и WhisperX.
- Перед аналитической LLM персональные данные должны быть обезличены.
- Supabase не хранит аудиозаписи постоянно.
- Анализ настраивается промтом.
- Факты о компании берутся из базы знаний.
- База знаний компании должна быть общей для нескольких продуктов, если это возможно.
- Продукты остаются независимыми.
- Руководитель получает отдельный дашборд с историей, метриками и доказательной базой.
- Менеджер получает обучающую обратную связь после разговора.
- На этапе требований не проектируются конкретные ноды, SQL и окончательная структура БД.

## Пока не определено

Это будущие задачи проектирования, а не вопросы, которые нужно решать сейчас:

- конкретный формат внутреннего пакета звонка;
- конкретный механизм фильтрации в n8n;
- окончательный выбор транскрибации и диаризации;
- способ сопоставления speaker с ролями менеджер/клиент;
- правила хранения сырой/обезличенной транскрипции;
- точная структура Supabase;
- окончательная структура CORE;
- формат промта и версионирование;
- структура общей базы знаний для нескольких продуктов;
- точные метрики руководителя;
- структура дашборда;
- права доступа и изоляция;
- надёжность, мониторинг и выпуск.

## Текущий режим

Продолжается формирование документационной основы непосредственно в этом репозитории.

Техническая реализация пока не разрешена. Следующие требования добавляются в соответствующие логические документы, а не в один общий накопительный файл.
