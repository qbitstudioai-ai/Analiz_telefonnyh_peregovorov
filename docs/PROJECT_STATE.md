## Последний завершённый блок

**DOC-08 — описано определение ролей МЕНЕДЖЕР/КЛИЕНТ.**

Обновлён [TRANSCRIPTION_AND_PRIVACY](specs/TRANSCRIPTION_AND_PRIVACY.md).

Зафиксировано:

- оцениваемый менеджер по CRM/телефонии и technical speaker менеджера — разные факты;
- приоритет имеют прямые доверенные данные источника: participant/extension/leg/channel и подтверждённые связи с сотрудником;
- направление, владелец сделки и смысл разговора являются только поддерживающими признаками;
- внешний аналитический LLM не используется как источник истины о роли;
- базовый шаблон не использует voice biometrics;
- роли имеют состояния «подтверждена», «предположена», «не определена» без выдуманного численного confidence;
- конфликт двух доверенных источников не разрешается догадкой;
- конференции, переводы и несколько сотрудников не сворачиваются насильно в два speaker;
- при неопределённых ролях надёжный менеджерский балл и надёжные речевые метрики не создаются;
- ручное исправление роли сохраняет историю и может потребовать новой версии анализа;
- контрольный набор DOC-07 используется также для проверки точности назначения ролей и критической инверсии МЕНЕДЖЕР↔КЛИЕНТ.
