# Метрики дашборда руководителя

Статус: согласованные определения v1.0. Документ задаёт единый смысл показателей; SQL и физические таблицы проектируются позднее.

## Общий контекст расчёта

Все показатели получают один набор глобальных фильтров из [DASHBOARD_DATA_MAP](../DASHBOARD_DATA_MAP.md). Период определяется по времени начала логического звонка в часовом поясе компании: начало включительно, конец не включительно.

Считаются уникальные внутренние ID логических звонков. Повтор webhook, дубль события и повторная техническая попытка не создают дополнительный звонок в показателе.

Если у звонка несколько версий анализа, используется одна текущая действующая версия. Архивная или оспоренная версия не попадает в агрегаты, но остаётся в истории.

## Активность

| Показатель | Определение |
|---|---|
| Все звонки | Число уникальных логических звонков, начавшихся в периоде и прошедших остальные фильтры |
| Оценённые клиентские | Клиентские разговоры с текущим завершённым анализом |
| Исключённые | Звонки с окончательным решением фильтра «исключён»; группируются по стабильному коду причины |
| Пропущенные клиентские | Подтверждённые источником клиентские звонки без состоявшегося разговора |
| Ожидающие/технически незавершённые | Звонки, не относящиеся к трём предыдущим категориям из-за ожидания данных или окончательной технической ошибки |
| Первые | Клиентские звонки без подтверждённой связи с более ранним звонком того же клиента/обращения |
| Повторные | Новые звонки с подтверждённой связью с прежним звонком клиента/сделки |

Разложение должно сходиться: все звонки равны сумме взаимоисключающих конечных категорий. Первые/повторные являются дополнительным разрезом клиентских разговоров и не добавляются к общей сумме второй раз.

## Качество анализа

| Показатель | Определение |
|---|---|
| Надёжные оценки | Число текущих завершённых анализов со статусом `nadezhno` |
| Предварительные оценки | Число текущих завершённых анализов со статусом `predvaritelno` |
| Официальный средний балл | Среднее арифметическое общих баллов текущих надёжных анализов выбранной выборки |
| Средний балл критерия | Среднее баллов текущих надёжных анализов, где конкретный критерий применим |
| Доля предварительных | Предварительные анализы / все завершённые анализы × 100% |

Значение «не применимо» исключается из числителя и знаменателя среднего критерия. Предварительный балл виден в карточке звонка, но по умолчанию не входит в официальный средний.

## Доведение до этапов

| Показатель | Определение |
|---|---|
| Дошли до этапа | Число надёжно проанализированных звонков, где этап отмечен достигнутым |
| Доля дошедших | Дошли до этапа / звонки, где этап применим × 100% |
| Последний достигнутый этап | Самый поздний достигнутый этап по согласованному порядку для конкретного звонка |
| Пропустили обязательный этап | Число звонков, где применимый обязательный этап отмечен пропущенным |

Отсутствие возражения означает «не применимо» и не мешает звонку достичь целевого действия.

## Результаты разговоров

| Показатель | Определение |
|---|---|
| Целевой результат ИИ | Уникальные оценённые клиентские звонки, где текущий ИИ-результат относится к разрешённым целевым кодам компании |
| Конверсия звонков по ИИ | Целевой результат ИИ / все оценённые клиентские звонки × 100% |
| Явный отказ | Уникальные звонки с текущим ИИ-результатом «явный отказ» |
| Отложенный спрос | Уникальные звонки с текущим ИИ-результатом «отложенный спрос» |
| Следующий контакт | Уникальные звонки с подтверждённой договорённостью о продолжении |
| Без результата | Уникальные оценённые звонки без целевого результата, отказа, отложенного спроса или подтверждённого продолжения |
| Подтверждённый CRM результат | Уникальные звонки/клиенты/сделки с целевым фактом CRM в согласованном окне атрибуции |

Показатели по звонкам и уникальным клиентам/сделкам выводятся отдельно с явным названием знаменателя. ИИ-результат не заменяет CRM-подтверждение.

## Пропущенные и перезвоны

| Показатель | Определение |
|---|---|
| Подтверждённый перезвон | Пропущенный клиентский звонок, связанный с последующим исходящим звонком по доверенным идентификаторам и окну компании |
| Доля перезвонов | Пропущенные с подтверждённым перезвоном / все пропущенные клиентские × 100% |
| Без перезвона | Пропущенные клиентские без подтверждённого связанного звонка по истечении окна |
| Время до перезвона | Начало связанного исходящего звонка минус время пропущенного; среднее/медиана показываются раздельно при необходимости |

Неоднозначная связь не считается перезвоном до подтверждения.

## Ошибки и сильные стороны

| Показатель | Определение |
|---|---|
| Частота наблюдения | Число уникальных звонков с текущим стабильным кодом ошибки/сильной стороны |
| Доля наблюдения | Уникальные звонки с кодом / надёжные анализы, где это наблюдение применимо × 100% |
| Менеджеры с наблюдением | Число уникальных менеджеров, у которых код встретился хотя бы в одном звонке выборки |

Нажатие на показатель передаёт стабильный код и открывает только образующие его звонки.

## Параметры речи

Показываются только когда локальная обработка сохранила достаточное качество сегментов и ролей:

| Показатель | Определение |
|---|---|
| Доля речи менеджера | Время речи менеджера / суммарное время речи обоих участников × 100% |
| Доля речи клиента | Время речи клиента / суммарное время речи обоих участников × 100% |
| Паузы | Количество и суммарная длительность пауз выше настроенного порога |
| Перебивания | Число подтверждённых пересечений речи по принятому правилу |
| Скорость речи | Число распознанных слов менеджера / минуты его речи |
| Длительность разговора | Конец состоявшегося разговора минус начало; техническое ожидание соединения не добавляется, если источник позволяет его отделить |

Пороги паузы и перебивания являются версионируемыми параметрами компании. Эти показатели не влияют на общий балл автоматически: такое влияние должно быть явно задано методикой.

## Динамика

Диаграмма строит среднее значение выбранного показателя по дням или неделям внутри периода. Она не формирует текстовый вывод «растёт/ухудшается» в первой версии. На точку диаграммы можно перейти к звонкам соответствующего интервала.

## Проверка воспроизводимости

Для каждой цифры должны быть доступны: активные фильтры, период и часовой пояс, версия определения, число строк в знаменателе и список звонков. Одинаковый набор фильтров обязан давать одинаковое значение на карточке, диаграмме, странице менеджера и в выгрузке.
