# Одна задача — одна сессия

Новая сессия проекта начинает работу с GitHub, а не с попытки восстановить весь старый чат.

ChatGPT сам предлагает переход после завершения небольшой задачи. Если контекст заканчивается раньше, допустима передача незавершённой задачи с точной контрольной точкой.

## Карточка задачи

| Поле | Что указать |
|---|---|
| ID | Постоянный ID из активного плана |
| Цель | Один конкретный результат |
| Исполнитель | ChatGPT / VSCode; ручные действия Павла отдельно |
| Условия начала | Зависимости, доступы, разрешённый режим |
| Обязательное чтение | Профильные документы задачи |
| Разрешённый объём | Файлы и среды, которые можно менять |
| Критерий готовности | Наблюдаемый результат и проверка |
| Текущее состояние | Что уже выполнено |
| Следующий шаг | Только одна задача или действие |

Не начинай реализацию, если PROJECT_STATE разрешает только документацию.

## Завершение сессии

1. Проверить критерий задачи.
2. Обновить основной документ, WORKPLAN_TEMPLATE и PROJECT_STATE.
3. Проверить ссылки, ID, статусы и отсутствие секретов.
4. Сохранить изменения и прочитать итоговый commit из GitHub.
5. Передать факты: что изменено, проверено, не проверено и применялось ли что-либо на сервере.
6. Указать только одну следующую задачу.

## Формат передачи

```text
ПЕРЕДАЧА В НОВУЮ СЕССИЮ
Проект: Analiz_telefonnyh_peregovorov
Репозиторий: https://github.com/qbitstudioai-ai/Analiz_telefonnyh_peregovorov
Ветка: <ветка>
Проверенный commit: <полный SHA>
Режим: <только документация / разрешённое проектирование / реализация / внедрение>
Компания и среда: <если применимо>

Задача: <ID; завершена / в работе / пауза>
Результат: <1–3 проверенных факта и основные файлы>
Проверено: <что именно и результат>
Не проверено: <что ещё не подтверждено>
На сервере: <не изменялся / точные применённые действия>
Препятствия: <нет / точное описание>
Следующая одна задача: <ID и цель>

Прочитай README.md, docs/CHATGPT_INSTRUCTIONS.md,
docs/PROJECT_STATE.md, docs/SESSION_HANDOFF.md,
docs/WORKPLAN_TEMPLATE.md и профильные документы следующей задачи.
Сверь SHA с текущей веткой main и учти более новые изменения.
Не повторяй уже подтверждённые действия.
```

## Если задача прервана

Зафиксируй последнее безопасно подтверждённое состояние и неоднозначные внешние действия.

Примеры будущего формата:

- «аудио получено, транскрибация не запускалась»;
- «исходящее действие создано, факт доставки неизвестен — повторно не отправлять до сверки»;
- «миграция подготовлена, на сервере не применялась».

Новая сессия сначала восстанавливает факты, затем продолжает.

## Задание VSCode

```text
Задача <ID>: <один результат>.
Репозиторий: <URL>; ветка: <ветка>; исходный SHA: <SHA>.
Прочитай: <обязательные документы>.
Измени только: <объём>.
Критерий готовности: <наблюдаемый результат>.
Проверки: <что выполнить>.
Обнови: <профильный документ>, WORKPLAN_TEMPLATE, PROJECT_STATE.
Выпуск на сервер: <не входит / явно разрешённый объём>.
Сделай commit и push.
Верни: файлы, проверки, что не проверено, серверные действия, commit SHA, препятствия.
```

ChatGPT после отчёта сам сверяет GitHub.
